O que você pode fazer

Funcionalidades principais implementadas nesta entrega.

  • Criar treino Cadastre treinos por nome e organize sua rotina.
  • Adicionar exercícios Relacione exercícios, séries e repetições a cada treino.
  • Registrar execução Salve quando um treino foi realizado com sucesso.

Objetivo do sistema

Centralizar o gerenciamento de treinos em uma interface simples e acessível.

O sistema também possui autenticação com cadastro, login e logout, permitindo acesso controlado às páginas.

Esta versão foi organizada para demonstrar funcionalidades reais de CRUD e fluxo de uso de um sistema web com Django.
